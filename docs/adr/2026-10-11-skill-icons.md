# ADR 2026-10-11: skill-icons: スキルのアイコンは skill-icons の形にそろえる

スキルのアイコンは [skill-icons](https://github.com/tandpfun/skill-icons)（MIT）の Dark 版（暗い角丸の枠）にそろえ、skill-icons に無いもの（Claude など）は [simple-icons](https://simpleicons.org/)（CC0）のロゴをブランド色で同じ枠に入れて作る。既存のアイコンが skill-icons の形で見た目をそろえたいためで、simple-icons だけでは形が合わず、AWS も収録されていない（[Issue #70](https://github.com/Kazu-K0032/profile/issues/70)）。
